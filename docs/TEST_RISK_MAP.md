# Test-to-Risk Map

**Reviewed:** 2026-08-01 after Stage 4

This map reports behavioral evidence, not a test-count badge. "Covered" means deterministic regression fixtures protect the implemented contract named here. "Partial" means useful tests exist but an important branch, integration boundary, or historical condition remains outside the fixture. A passing suite does not validate the research conclusion.

## Maintenance rule

Whenever behavior changes, update this map in the same logical change. Name the exact test protecting the risk and retain the residual gap. Historical findings and figures are not silently regenerated by tests or schema initialization; an explicit result-changing rerun must be documented separately.
